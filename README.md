# Live Resource Inspector

Расширение Google Chrome, которое показывает, из чего состоит открытая вкладка: какие адреса она запрашивает, на какие домены ходит и какие ссылки, картинки, видео, аудио и прочие ресурсы есть на странице. Смотреть это можно без DevTools и без разбора исходного кода.

Сбор идёт сам, пока открыт обычный сайт. Иконка расширения открывает маленькое окно со счётчиками. Клик по счётчику переносит в полный анализатор уже на нужном разделе: запросы, уникальные адреса, домены, ссылки из страницы, видео, аудио, игровые кандидаты или ошибки. Там можно искать, фильтровать, выделять строки, копировать списки и сохранять их в TXT, CSV или JSON.

Расширение только наблюдает. Запросы не блокируются и не меняются, файлы сами не скачиваются, найденный JavaScript не выполняется. Своего сервера нет: адреса и метаданные остаются на компьютере, в IndexedDB и локальном хранилище Chrome. Cookies, пароли, тела запросов и заголовки авторизации не читаются и не попадают в экспорт.

Интерфейс собран на библиотеке VUI. Пока тему не выбрали руками, оформление следует системе: светлое или тёмное, как в ОС. В шапке анализатора и во всплывающем окне можно закрепить светлую, тёмную, контрастную или одну из неоновых тем.

## Требования

- Node.js 20 или новее
- Актуальный стабильный Chrome 120+

## Команды

```bash
npm install
npm test
npm run typecheck
npm run lint
npm run build
npm run fixtures
```

`npm run dev` собирает расширение и оставляет Vite в режиме наблюдения. После изменения кода на странице `chrome://extensions` нужно нажать «Обновить».

`npm run fixtures` поднимает страницы сценариев на `http://127.0.0.1:4173`.

## Установка

1. Выполнить `npm run build`.
2. Открыть `chrome://extensions`.
3. Включить режим разработчика.
4. «Загрузить распакованное расширение» и выбрать папку `dist`.

Публикация в Chrome Web Store не настроена.

## Использование

1. Открыть обычный сайт (`http` или `https`). Сбор для открытых вкладок начинается сам, без кнопки «Начать».
2. Нажать иконку расширения. В маленьком окне те же счётчики, что в анализаторе: запросы, уникальные URL, домены, ссылки, видео, аудио, игровые кандидаты и ошибки.
3. Клик по плашке открывает анализатор сразу в этом разделе. Клик по домену открывает общий список ресурсов. «Пауза» останавливает приём новых записей, «Продолжить» возвращает его.

Поиск идёт по всему набору сессии. Категории комбинируются с текстом. Длинные списки виртуализированы. Большой экспорт, который не помещается в буфер обмена, сохраняется файлом. Тема, выбранная вручную, запоминается на этом устройстве.

Область сбора в настройках:

- «Только текущий документ» — полная навигация или перезагрузка начинает новую сессию. Переходы SPA остаются в текущей.
- «Вся вкладка» — одна сессия живёт через загрузки и SPA.

## Ограничения

Расширение не обещает увидеть каждый сетевой обмен.

- `webRequest` не показывает кадры WebSocket и закрытие соединения, только рукопожатие.
- `blob:` записывается как локальный адрес. Это не URL сервера. Рядом может быть исходный адрес из DOM или сети.
- `data:` не сохраняется: такие URL часто содержат само содержимое.
- Недоступны `chrome://`, Chrome Web Store, страницы других расширений и часть внутренних запросов браузера.
- Запросы видны для `http`, `https`, `ws` и `wss`: доступ к сайтам выдаётся при установке расширения. Событие приходит, только если доступ есть и к инициатору, и к адресу запроса.
- Предполётные CORS-запросы не запрашиваются: для них нужен `extraHeaders`, а вместе с ним расширение начало бы видеть cookies.
- Тела запросов, cookies, пароли и заголовки авторизации не читаются и не экспортируются.
- Файл `file://` намеренно не входит в запрашиваемый доступ.
- Песочница iframe, DRM и закрытые медиаконтексты могут не отдать исходный адрес.
- Service worker может быть остановлен. Записи пишутся в IndexedDB пачками; при убийстве процесса в момент записи возможна потеря последней пачки. Открытый анализатор держит соединение и уменьшает этот промежуток.
- После полного перезапуска браузера идентификаторы вкладок меняются. Старые сессии остаются в базе как архив, но не привязываются к новым вкладкам.
